# Smart Health Management System (SHMS)

A web-based Smart Health Management System built with Django and PostgreSQL.

## 🚀 Tech Stack

- Python 3.x
- Django
- PostgreSQL
- HTML5
- CSS3
- Bootstrap 5
- Git & GitHub

## 📁 Project Structure

```
config/
accounts/
dashboard/
patients/
templates/
static/
media/
```

## ✨ Features Implemented

### Authentication
- Custom User Model
- Role-based User System
- Admin Login

### Dashboard
- Dashboard App
- Base Layout
- Navigation Structure

### Patient Module
- Patient Registration
- Automatic Patient ID Generation
- Patient List
- User ↔ Patient One-to-One Relationship
